Privacy Protocol.

01 / DATA ENCRYPTION

All visual captures (images) and metadata (OCR text, color data, notes) are processed and stored exclusively within the device's local secure storage. VizStash utilizes an encrypted local database to ensure your archive remains private.

02 / NO CLOUD SYNC

VizStash is built on a "Local First" philosophy. No raw item data, OCR strings, or imagery is ever transmitted to external servers or cloud accounts. We do not maintain off-device backups of your stash.

03 / OCR PROCESSING

Intelligence processing (Object Character Recognition) is performed using localized machine learning models (Google ML Kit). This processing occurs entirely on the device CPU/GPU and does not require an active internet connection for analysis.

04 / USER CONTROL

The device operator maintains 100% control over the visual archive. All database entries can be wiped instantly via the "Clear All Data" function in the app settings, which removes both the database records and physical image files.
